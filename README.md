# Environmental abstraction from interaction enables microrobot navigation in physically complex environments

This repository contains the code associated with our manuscript:

**"Environmental abstraction from interaction enables
microrobot navigation in physically complex
environments"**

---

## Overview

Conventional robots rely on onboard sensing to obtain environmental infor-
mation for autonomous navigation. For microrobots, however, onboard sensors
are difficult to integrate due to their ultra-small sizes, leading to challenges for
autonomous navigation in physically complex environments, such as varying fluid
flow, medium resistance, and surface geometry.

This repository provides our source code.
